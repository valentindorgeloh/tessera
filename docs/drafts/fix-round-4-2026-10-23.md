  `onPointerDown` reaches the DOM.
- Astryx `TabList` reads tabs from the DOM (`[data-tab-value]`), not from React children.

**Design answers** (from the 0.6.8 typings):

- **DropdownMenu, not NavHeadingMenu.** `NavHeadingMenu` is documented only "as the menu
  prop of SideNavHeading or TopNavHeading", and `NavHeadingMenuItem` spreads no rest props,
  so it cannot carry `aria-current`. `DropdownMenuItem` takes `href`, `label`, `icon` and
  `endContent`, and spreads `aria-*` onto the row. So no Popover is needed: the
  `DropdownMenu` positions its own popover (`placement` 'below', `alignment` 'start').
  Compound mode is popover-only, which is what we want. Data mode can be a bottom sheet.
- **`SectionMenu` API:**
  `SectionMenu({ label, entries, currentKey, className })`, where
  `entries: readonly { key: string; label: string; href: string; icon?: IconType; endContent?: ReactNode }[]`.
  It renders:
  - The root `HStack className={"tessera-section-menu " + className}`.
  - Inside it, `<DropdownMenu aria-label={label} menuWidth={240} alignment="start" renderTrigger={(p) => <Button {...p} … />}>`
    with `DropdownMenuItem` children.
  - The menu is named by `aria-label` (DropdownMenu.js l.946-947: with `renderTrigger`,
    `aria-label` wins over `aria-labelledby`). Pass `${project.name} pages` and
    "Project settings", the strips' own names.
- **Trigger:** an Astryx `Button` with:
  - `size="sm"` and `variant="ghost"`
  - `label` = the current entry's label (ASSUMPTION: "Sections" when none matches)
  - `icon` = its icon
  - `endContent={<Icon icon={CaretDownIcon} size="sm" />}`
  - `className="tessera-section-menu-button"`
  - The theme gives it the 44px hit area. Spread every trigger prop: they carry the press,
    the keyboard (Enter, Space and the arrows open it) and the focus return on Escape.
- **Items:** one `DropdownMenuItem` per entry. The current entry gets
  `aria-current="page"` and `endContent={<Icon icon={CheckIcon} size="sm" />}`. In the
  project menu the Intake entry keeps its count `Badge` as `endContent`. Icons come from
  `src/themes/catppuccin/icons.tsx` (`CaretDownIcon` l.194, `CheckIcon` l.252).
